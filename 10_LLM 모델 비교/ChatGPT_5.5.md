좋은 과제입니다. 이 과제의 핵심은 **"AI를 사용하는 사람"에서 "AI를 설계하고 평가하는 사람"으로 발전하는 것**입니다.

먼저 질문에 답하겠습니다.

## 나는 누구인가?

저는 OpenAI의 GPT 계열 LLM(대규모 언어모델)인 ChatGPT입니다.

이번 과제에서는 저뿐 아니라 다음과 같은 다른 LLM과 비교하게 됩니다.

* [ChatGPT(OpenAI)](https://openai.com/chatgpt?utm_source=chatgpt.com)
* [Claude(Anthropic)](https://www.anthropic.com/claude?utm_source=chatgpt.com)
* [Gemini(Google)](https://gemini.google.com?utm_source=chatgpt.com)

과제의 목적은

> "어떤 AI가 최고인가?"

가 아니라

> "특정 업무에 가장 적합한 AI를 어떻게 선정할 것인가?"

를 배우는 것입니다.

---

# 1. 과제를 한 문장으로 요약

**동일한 업무를 여러 AI에게 시켜보고, 결과를 평가하고, 좋은 프롬프트를 설계하여 업무용 AI 챗봇을 만드는 프로젝트**

입니다.

---

# 2. 무엇을 배우는 과제인가?

이 과제를 통해 5가지를 배우게 됩니다.

## ① LLM의 동작 원리

LLM은 사실을 저장한 데이터베이스가 아닙니다.

다음 단어를 확률적으로 예측합니다.

예)

입력

> 대한민국의 수도는

AI 내부

> 서울(확률 98%)
> 부산(확률 1%)
> 인천(확률 1%)

따라서

### 환각(Hallucination)

이 발생할 수 있습니다.

예)

질문

> 2032년 한국 대통령은?

AI

> ○○입니다.

(실제로는 알 수 없음)

이런 경우를 환각이라고 합니다.

---

## ② 프롬프트 엔지니어링

질문의 품질이 결과를 결정합니다.

### 나쁜 프롬프트

```
회의록 요약해줘
```

### 좋은 프롬프트

```
당신은 PM입니다.

다음 회의록을 분석하세요.

출력형식:
1. 결정사항
2. Action Item
3. 담당자
4. 일정

추측하지 말고
근거가 없는 내용은
'확인 필요'로 표시하세요.
```

---

## ③ AI 모델 비교 방법

느낌으로 평가하면 안 됩니다.

예)

| 평가항목 | GPT | Claude | Gemini |
| ---- | --- | ------ | ------ |
| 정확성  | 5   | 4      | 4      |
| 한국어  | 5   | 4      | 4      |
| 형식준수 | 5   | 5      | 3      |
| 문맥유지 | 5   | 5      | 4      |
| 속도   | 4   | 4      | 5      |

이렇게 점수와 근거로 평가합니다.

---

## ④ 시스템 프롬프트 설계

AI의 직업과 성격을 정의하는 것입니다.

예)

```
당신은 15년 경력의
프로젝트 매니저입니다.

회의록을 분석하여

- 결정사항
- 리스크
- Action Item

만 추출합니다.

모르면 모른다고 말합니다.
```

AI의 역할을 지정하는 것이죠.

---

## ⑤ 검증 및 개선

AI가 틀린 정보를 만들었는지 검사합니다.

예)

질문

```
대한민국 수도는?
```

정답

```
서울
```

질문

```
2028년 대통령은?
```

정답

```
알 수 없음
```

AI가

```
2032년 대통령은 홍길동입니다.
```

라고 하면 Fail입니다.

```
규칙:

3. 담당자 표시
4. 일정 표시

출력형식:

# 결정사항

# Action Item

# 리스크

# 확인 필요
```

# 6. Few-shot 작성

Few-shot은

"예시를 보여주는 것"

입니다.

---

예시1

입력

```
회의에서 홈페이지 개편을
6월까지 완료하기로 했다.
```

출력

```
결정사항:
홈페이지 개편 진행

Action Item:
담당자: 개발팀
기한: 6월
```

---

예시2

입력

```
마케팅 예산을 10% 증액한다.
```

출력

```
결정사항:
마케팅 예산 10% 증액

Action Item:
재무팀 예산 수정
```

---

예시3 (모호한 사례)

입력

```
예산은 나중에 정하자.
```

출력

```
확인 질문:
예산 결정 예정일이 있습니까?
```

# 7. v1 → v2 개선

## v1

```
회의록 요약해줘
```

---

## v2

```
1단계
결정사항 파악

2단계
Action Item 추출

3단계
정보 부족 여부 확인

4단계
템플릿 출력

추측 금지
```

### 과제를 잘 받기 위한 팁

이 과제는 사실상 **"AI 활용 능력 평가"** 입니다.

교수나 평가자가 보고 싶은 것은:

1. AI를 여러 개 비교했는가?
2. 왜 그 모델을 선택했는가?
3. 프롬프트를 개선했는가?
4. 환각을 검증했는가?
5. 재현 가능한 문서로 정리했는가?

입니다.

현재 과제 기준으로는 **"회의록 요약 업무 자동화 챗봇"**을 주제로 진행하는 것이 가장 쉽고, 요구사항 충족률도 가장 높습니다. 또한 보고서 작성량 대비 평가 점수를 얻기 유리합니다.
